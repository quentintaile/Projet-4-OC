# Chess Tournament Manager

## Description

Ce projet permet de gérer des tournois d'échecs pour un club local. Le programme fonctionne entièrement hors ligne, utilise la programmation orientée objet et applique le design pattern MVC pour organiser le code.

Les fonctionnalités principales comprennent :
- Ajout et gestion des joueurs.
- Création et gestion des tournois (avec plusieurs tours et appariements).
- Sauvegarde et chargement des données en format JSON.
- Génération de rapports pour suivre l’avancement du tournoi.

## Prérequis

- **Python 3.x** installé sur votre machine.
- Aucun serveur ou connexion Internet n'est nécessaire.
